# earnapp.fr

Site de présentation indépendant en français consacré à EarnApp. Il explique le fonctionnement du service, ses principales conditions et les étapes d’inscription.

## Contenu

- `index.html` — page d’accueil du site, autonome et directement publiable.

## Prévisualisation

Ouvrez `index.html` dans un navigateur pour consulter le site localement.

## Publication

Publiez le contenu du dossier sur un hébergement de site statique. Pour GitHub Pages, ajoutez `index.html` et ce README à la branche configurée pour la publication, puis sélectionnez la branche et le dossier source dans les paramètres Pages du dépôt.

## À propos

Ce site est une présentation indépendante et n’est pas le site officiel d’EarnApp. Certains liens d’inscription peuvent être affiliés. Les conditions du service officiel font référence.
